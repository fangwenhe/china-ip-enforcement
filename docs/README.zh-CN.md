# 中国知产维权与品牌保护指南（面向外国品牌/跨境卖家）

[English](../README.md) | **中文**

> 面向外国品牌、跨境电商卖家和海外律所的中国维权实操手册：商标异议、无效宣告、撤三、平台下架、亚马逊品牌备案（中国商标）、海关备案。

**品牌名被抢注？天猫/抖音上有人抄你链接？亚马逊品牌备案一直不过？** 本仓整理了维权路径、期限、费用和模板，由中国备案商标代理机构维护。

## 维权路径决策

```
抢注商标处于什么状态？
├─ 还在 3 个月公告期
│  └─ 提异议（成本最低、成功率最高）
├─ 已注册
│  ├─ 恶意抢注/在先权利，注册 5 年内
│  │  └─ 无效宣告
│  ├─ 连续 3 年未在中国使用
│  │  └─ 撤三（撤销连续三年不使用）
│  └─ 绝对理由（欺骗性、禁用标志）
│     └─ 无效宣告（不受 5 年限制）
└─ 商标有效且在使用
   └─ 谈判转让，或共存/许可协议
```

## 平台投诉（天猫/淘宝/抖音/拼多多/京东/1688）

- 需准备：中国商标注册证或著作权登记证 + 侵权链接截图 + 权属材料
- 验证通过后通常 3–14 天下架；亚马逊备案后 1–7 天
- 模板见：[平台投诉声明模板（中英）](../templates/platform-takedown-template.md)

## 亚马逊品牌备案（中国商标）

- 两大硬条件：品牌名**永久固定**在产品/包装上；持有亚马逊认可机构签发的®标或™申请
- 大陆公司备齐营业执照+统一社会信用代码；香港公司备商业登记证
- CNIPA 留存的联系邮箱必须可收信（验证码会发到商标联系人）
- 完整清单：[Amazon Brand Registry China 备案清单](../checklists/amazon-brand-registry-china.md)

## 海关备案

- 向中国海关备案商标/版权，口岸假货自动扣留并通知权利人
- 有效期 10 年，可续展，官方免费
