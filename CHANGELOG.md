## [1.1.0] - 2026-10-13
- Added second free tool **Trademark Squatter Removal Route Chooser** (`trademark-squatter-removal-route-chooser.html`) — maps the squatter's CNIPA status (pending / in publication / registered <5y / unused 3y / registered >5y) and the user's rights to the correct route (opposition / invalidation / non-use cancellation / buy-back), with statutory deadlines, official fees, timeline and evidence; targets the zero-competition queries "trademark squatting china" / "bad faith trademark china".
- Added FAQ entry on removing a mark registered for over 5 years; linked the new tool from index (card + ItemList JSON-LD), README and sitemap.
- Uses the final 2026 amendment (effective 1 Jan 2027): opposition 2 months (Art. 36), ex officio 3-year revocation (Art. 57), online use as genuine use (Art. 2), CNY 100,000 bad-faith fine (Art. 54), no-use-intent refusal (Art. 19); no five-year statement of use (that draft item was not adopted).
